# Del Pla al Seguiment · Descàrregues

**COMPLET_V1** és el recorregut complet: nou casos, un repte per cas, quatre capítols de Planificació i cinc de Seguiment. Durada objectiu: uns cinc minuts, pendent de prova amb participants. Adaptat a ordinador i mòbil, amb desat automàtic en el mateix navegador.

Per descarregar, obre un dels fitxers i utilitza «Download raw file» a GitHub. El repositori pot requerir iniciar sessió amb el compte que hi té accés.

- **Del_Pla_al_Seguiment_COMPLET_V1.html**: el joc complet. Descarrega’l i obre’l amb el navegador.
- **Del_Pla_al_Seguiment_COMPLET_V1.zip**: el mateix joc, amb les fonts, les imatges i la documentació per treballar noves versions.
- **Del_Pla_al_Seguiment_BASE_01.html** i **.zip**: exemple anterior conservat com a referència, amb el Capítol 1 jugable.

## Com descarregar i jugar

1. Obre **Del_Pla_al_Seguiment_COMPLET_V1.html**.
2. A la part superior del fitxer, prem la icona de descàrrega **Download raw file**. Si apareix «View raw», també pots obrir-lo i desar-lo.
3. Obre el fitxer HTML descarregat amb Chrome, Edge, Firefox o Safari. GitHub mostra el codi; no executa el joc en aquesta pàgina.

Si baixes el ZIP, descomprimeix-lo i obre **joc.html** dins de la carpeta.

L’editor senzill es desenvoluparà quan el contingut client estigui tancat.
